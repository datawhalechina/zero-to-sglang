# 社区贡献专区

欢迎来到社区贡献专区，欢迎大家积极参与课程并且分享自己的经验。

包括但不限于：学习课程的经验；自己手搓了 mini-sglang，把手搓过程中遇到的 bug 和问题总结出来形成读书笔记；或者之前配置 SGLang 踩过的坑、认为值得注意的地方，都可以作为贡献。

PR 贡献时，请阅读或者让 AI 核对：[PR_requirement.md](./PR_requirement.md)，提交之前请逐条核实。

## 目录

| 目录 | 放什么 |
|------|--------|
| `builds/` | 手搓 mini-sglang 的过程记录：哪一步出了什么 bug，怎么查的，怎么改的 |
| `pitfalls/` | 装 SGLang、配环境踩的坑，以及文档没写清楚、想提醒别人的地方 |
| `notes/` | 学习笔记，或者课程没展开的推导、实验 |

## 怎么提

Fork，从 `main` 切分支，写完提 PR。提之前把 [PR 要求](./PR_requirement.md) 过一遍。
