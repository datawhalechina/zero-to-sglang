# 社区贡献 PR 要求

提交之前逐条核实。不满足的 PR 会被打回。

1. 文件放在 `community/ch/` 下对应的目录：`builds/` 手搓复现记录、`pitfalls/` 踩坑与注意事项、`notes/` 学习笔记。文件名用中文，一眼能看出主题。
2. 文首写清楚环境：GPU 型号、驱动和 CUDA 版本、SGLang 版本（tag 或 commit）、Python 和 PyTorch 版本。踩坑类内容没有环境信息无法复现。
3. 图片放在对应目录的 `images/` 下，用 HTML 标签引用，宽度 800。
4. 日志、报错、命令一律用代码块，不要截图。
5. 正文、图表、参考资料里不点名其他推理项目，不拿其他项目的数字做对比。需要对比时说「其他推理引擎」。
6. 内容必须是自己动手验证过的。不收纯转载、纯翻译，不收和课程正文重复的内容（这种直接改正文）。
7. 用自己的话写。AI 可以帮你整理，但发出来之前自己通读一遍，保证每句话你都认。PR 描述同理：改了什么、为什么，不要整段贴 AI 的输出。
8. 参考资料只列真正看过、用到的。
9. 同一个 PR 里同步更新 [index.md](./index.md) 的「已收录」表：加一行，写日期、目录、标题、作者。
10. 提交即视为同意本专区内容采用 CC BY-NC-SA 4.0 协议，与课程正文一致。
